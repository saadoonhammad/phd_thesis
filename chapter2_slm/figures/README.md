Figures reported in Chapter 2, produced by the notebooks in `../notebooks/` from the data in `../data/`.

- Included studies by year

## Distributions of the included studies

- Algorithms
- Algorithm taxonomy
- Hardware families
- Data types
- Libraries and tools by role
- Evaluation metrics
- Connectivity
- Application domains
- Power supply

All distribution figures are computed over the 94 included studies. Multi-label fields (algorithms, hardware, data types, libraries, metrics, connectivity) count every instance, so a study can contribute to more than one category. Domain is single-label.
